# 🏢 Kopma Unila Web Platform
Platform manajemen berbasis web dan sistem backend terpadu untuk Koperasi Mahasiswa Universitas Lampung (KOPMA Unila) dan ekosistem aplikasi **SiJuko**. Aplikasi ini memfasilitasi integrasi data anggota, pengolahan simpanan, manajemen alumni, serta publikasi kegiatan organisasi secara digital.ss

---

## 🌟 Fitur Utama

- **Manajemen & Sinkronisasi Anggota:** Pengolahan data anggota terpusat dengan fitur sinkronisasi otomatis data simpanan.
- **Portal Informasi & Alumni:** Pengelolaan direktori alumni/demisioner lengkap dengan pemfilteran berbasis fakultas dan kustomisasi slug dinamis.
- **Manajemen Kegiatan Organisasi:** Dashboard publikasi berita, artikel, dan dokumentasi agenda KOPMA Unila.
- **Infrastruktur SiJuko:** Endpoint backend dan pengolahan data pendukung untuk ekosistem aplikasi **SiJuko**.
- **User Management & Authentication:** Sistem otentikasi berbasis peran (*role-based access*) untuk pengurus dan anggota.

---

## 🛠️ Tech Stack
- **Framework:** CodeIgniter 4 (PHP)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap / Custom Layouts
- **Tools & Libraries:** Composer, cPanel Deployment Script (`.cpanel.yml`), PHPMailer / SMTP Integration
